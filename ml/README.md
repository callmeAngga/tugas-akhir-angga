### Terkait Virtual Environment

- Step 1: Buat folder venv bernama 'venv' di repo
 python -m venv venv

- Step 2: Aktivkan venv
 venv\Scripts\activate

- Step 3: Download semua library yang dibutuhkan untuk pengerjaan model Prophet dan XGBoost
 pip install pandas numpy matplotlib jupyter scikit-learn xgboost prophet
